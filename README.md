# Artifacts

Companion artifacts (sample code, documents and other supporting material) for
Fullstacko's [Research](https://www.fullstacko.com/research) and
[Writing](https://www.fullstacko.com/writing).

## Repository layout

Each artifact lives in a folder named after the piece it accompanies, grouped by
type:

| Folder | Contents |
| - | - |
| [writing/](writing/) | Artifacts for published articles. |
| [research/](research/) | Artifacts for published research. |

Every artifact folder has its own `README.md` covering setup, a file table and
run instructions. Start there. For example:
[writing/mcp-rebuilt-for-production](writing/mcp-rebuilt-for-production/README.md).

## Using the artifacts

The code is educational and meant to support the piece it accompanies, not to
be used in production. Each artifact's README states the versions it was
verified against.
